# SmartProcure360 - SAP Data Elements

This folder documents the custom SAP Dictionary data elements used by the SmartProcure360 procurement and vendor risk management system.

## Package

```text
ZSP360
SmartProcure360 - Procurement & Vendor Risk
```

## Purpose

Data elements provide the semantic definition of business fields in the SmartProcure360 SAP data model.

The custom `ZSP360_E_*` data elements are based on reusable SAP domains and are used by:

- Custom database tables
- ABAP classes
- ABAP reports
- CDS views
- OData services
- SAPUI5 frontend bindings

# Usage in ABAP Risk Engine

The data elements are directly used in the signatures and calculations of:

```text
ZCL_SP360_RISK_ENGINE
```

For example:

```abap
IV_DELIVERY_SCORE TYPE ZSP360_E_SCORE
IV_QUALITY_SCORE  TYPE ZSP360_E_SCORE
IV_PRICE_SCORE    TYPE ZSP360_E_SCORE
IV_HISTORY_SCORE  TYPE ZSP360_E_SCORE

RV_RISK_SCORE     TYPE ZSP360_E_RISK_SCORE
RV_RISK_LEVEL     TYPE ZSP360_E_RISK_LEVEL
RV_RECOMMENDATION TYPE ZSP360_E_STATUS
```

This allows the risk engine to work with the same semantic definitions used by the database layer.

# SAP Technical Notes

Data elements were created in the SAP ABAP Dictionary using:

```text
SE11
```

They belong to package:

```text
ZSP360
```

Each custom data element references an appropriate SmartProcure360 domain.

This separation provides:

```text
Domain
  ↓
Data Element
  ↓
Table Field
```

which improves consistency and maintainability of the SAP data model.

# Summary

The SmartProcure360 data element layer provides reusable semantic definitions between the SAP domains and database tables.

The data elements standardize:

- Vendor identifiers
- Vendor master information
- Procurement document identifiers
- Material and quantity fields
- Monetary values
- Currency
- Delivery and quality identifiers
- Risk scores
- Risk levels
- Approval identifiers
- Audit identifiers
- Procurement status and priority

Together with domains, database tables, ABAP business logic, CDS views and OData services, the data elements form an important part of the SmartProcure360 SAP data model.
